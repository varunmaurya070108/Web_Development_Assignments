JavaScript

JavaScript is a popular programming language mainly used to make websites interactive and dynamic. It can be used to create buttons, animations, forms, games, and many other web features. JavaScript can run directly in a web browser and is an important technology for web development.


Code Example: 
let name = "Varun";
console.log("Hello " + name);
console.log("Welcome to JavaScript");

"JavaScript is mainly used to add interactivity to web pages."

Java

Java is a general-purpose programming language widely used for developing applications, web applications, enterprise software, and Android applications. It follows the object-oriented programming approach and is designed to be portable across different platforms.
Code Example: 

String name = "Varun";
System.out.println("Hello " + name);
System.out.println("Welcome to Java");

"Java is an object-oriented programming language."

Python

Python is a simple and beginner-friendly programming language used for web development, automation, data analysis, artificial intelligence, and machine learning. Its simple syntax makes it easy to learn and understand, especially for beginners.
Code Example: 

name = "Varun"
print("Hello", name)
print("Welcome to Python")
"Python is known for its simple and readable syntax."
