Mathematics Formula Sheet

Algebra-

(a+b)2 = a2 + b2 + 2ab

(a-b)2 = a2 + b2 - 2ab

(a+b)(a-b) = a2 - b2

a3 + b3 = (a+b)(a2 + b2 - ab)

a3 - b3 = (a-b)(a2 + b2 + ab)

Geometry-

Area of a triangle = 1/2 x b x h

Mensuration-
