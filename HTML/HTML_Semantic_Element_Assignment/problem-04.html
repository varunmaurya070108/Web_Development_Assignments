AeroBook Pro 14 — Ultra-Slim Performance Laptop

The AeroBook Pro 14 combines flagship performance with an ultra-portable design. Powered by the latest processors and a stunning display, it is built for creators, professionals and students alike.

Overview

Featuring up to 32GB RAM and blazing-fast NVMe storage, the AeroBook Pro 14 delivers desktop-class performance in a lightweight body weighing just 1.3kg.

Key Features

  • 14-inch 2.8K OLED display
  • Up to 32GB LPDDR5 RAM
  • Up to 1TB NVMe SSD storage
  • 165Hz refresh rate*
  • Backlit keyboard with fingerprint sensor

*Available on select configurations only.

Specification Glossary

RAM
Random Access Memory — temporary memory used for active tasks and applications.
SSD
Solid State Drive — fast, non-mechanical storage for the operating system and files.
Refresh Rate
The number of times per second the display updates the image, measured in Hz.
Warranty
The manufacturer's commitment to repair or replace the product under specified conditions.
